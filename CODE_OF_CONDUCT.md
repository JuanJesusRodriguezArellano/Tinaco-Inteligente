# Código de Conducta

## Compromiso

Como equipo nos comprometemos a mantener un ambiente de trabajo respetuoso y colaborativo durante todo el cuatrimestre.

## Estándares

- Comunicación respetuosa y constructiva
- Aceptar feedback en code reviews sin tomarlo personal
- Respetar los horarios de trabajo acordados
- Documentar lo que se hace para que el equipo entienda
- Hacer commits frecuentes y descriptivos

## Responsabilidades

Cada integrante es responsable de su área asignada y de comunicar bloqueos a tiempo para que el equipo pueda ayudar.
